# Kiakia

*Every customer, answered fast.* ("Kiakia" means "quickly" in Yoruba.)

One simple inbox for small businesses that sell through chat. Kiakia brings in messages from WhatsApp,
Instagram and Facebook (later TikTok, Telegram and email), shows you which customers are still waiting,
turns voice notes into text, and sends payment links from inside the chat.

Messaging only: no CRM, no marketing broadcasts.

See [PLAN.md](PLAN.md) for the full plan: problems, architecture, data model and roadmap.
